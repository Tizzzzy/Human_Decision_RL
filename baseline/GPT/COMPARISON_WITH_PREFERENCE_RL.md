## Prompt & Output Format

### Prompt (Identical)
```
Task: Analyze the provided Social Media post for linguistic markers of AI or human authorship.

Constraints:
1. Start the response IMMEDIATELY with the bulleted list.
2. Do NOT provide an introduction, a final verdict, or a summary.
3. Do NOT group the bullet points into sub-headings (keep it a flat list).
4. Every bullet point MUST follow one of these two exact templates:
    - "Look for [linguistic category or type of phrasing]."
    - "Look for [linguistic category or type of phrasing] like '[short example]'."
5. When providing examples, you may list multiple words separated by commas.
6. Do NOT use bolding, italics, or any special Markdown formatting.
7. Limit the output to exactly 2 to 6 bullet points.
```

### Output JSON (Identical)
```json
{
  "text_id": "reddit_2932",
  "label": "Human",
  "text": "Full text content...",
  "explanation": "- Bullet point 1\n- Bullet point 2\n- Bullet point 3"
}
```

## Detailed Comparison Script

Create `/gpfs/projects/p32143/RL_human_decision/baseline/GPT/compare_explanations.py`:

```python
#!/usr/bin/env python3
"""
Compare explanations generated by GPT and Preference_RL models.
Outputs: quality metrics and sample comparisons.
"""

import json
import os
import glob
from pathlib import Path
from typing import List, Dict
import re

# ==========================================
# Configuration
# ==========================================
GPT_RESULTS_DIR = "/projects/p32143/RL_human_decision/baseline/GPT/inference_results"
PREF_RL_RESULTS_DIR = "/projects/p32143/RL_human_decision/baseline/preference_RL/inference_results"

# ==========================================
# Helper Functions
# ==========================================
def load_latest_results(directory: str) -> Dict:
    """Load the most recent results file from directory."""
    files = glob.glob(os.path.join(directory, "*.json"))
    if not files:
        return {}
    
    latest_file = max(files, key=os.path.getmtime)
    print(f"Loading: {latest_file}")
    
    with open(latest_file, 'r') as f:
        return json.load(f)


def count_bullet_points(explanation: str) -> int:
    """Count the number of bullet points in an explanation."""
    lines = explanation.strip().split('\n')
    bullets = [l for l in lines if l.strip().startswith(('- ', '• ', '* '))]
    return len(bullets)


def extract_examples(explanation: str) -> List[str]:
    """Extract example phrases from explanation."""
    # Pattern: "like '...' " or "like \"...\""
    pattern = r"like\s+['\"]([^'\"]+)['\"]"
    matches = re.findall(pattern, explanation)
    return matches


def calculate_explanation_length(explanation: str) -> int:
    """Calculate average bullet point length."""
    lines = explanation.strip().split('\n')
    bullets = [l for l in lines if l.strip().startswith(('- ', '• ', '* '))]
    if not bullets:
        return 0
    return sum(len(b) for b in bullets) // len(bullets)


def compare_explanations(gpt_results: List[Dict], pref_rl_results: List[Dict]):
    """Compare explanations from both models."""
    print("\n" + "="*70)
    print("Explanation Comparison: GPT vs Preference_RL")
    print("="*70)

    # Create text_id -> result mappings
    gpt_by_id = {r['text_id']: r for r in gpt_results}
    pref_by_id = {r['text_id']: r for r in pref_rl_results}

    # Find common texts
    common_ids = set(gpt_by_id.keys()) & set(pref_by_id.keys())
    print(f"\nCommon texts: {len(common_ids)}")

    # Calculate metrics
    gpt_bullets = []
    pref_bullets = []
    gpt_lengths = []
    pref_lengths = []
    gpt_examples = []
    pref_examples = []

    for text_id in common_ids:
        gpt_exp = gpt_by_id[text_id]['explanation']
        pref_exp = pref_by_id[text_id]['explanation']

        gpt_bullets.append(count_bullet_points(gpt_exp))
        pref_bullets.append(count_bullet_points(pref_exp))

        gpt_lengths.append(calculate_explanation_length(gpt_exp))
        pref_lengths.append(calculate_explanation_length(pref_exp))

        gpt_examples.extend(extract_examples(gpt_exp))
        pref_examples.extend(extract_examples(pref_exp))

    # Print statistics
    print("\n" + "="*70)
    print("Metrics")
    print("="*70)

    print("\nBullet Points per Explanation:")
    print(f"  GPT:          avg={sum(gpt_bullets)/len(gpt_bullets):.1f}, "
          f"min={min(gpt_bullets)}, max={max(gpt_bullets)}")
    print(f"  Preference_RL: avg={sum(pref_bullets)/len(pref_bullets):.1f}, "
          f"min={min(pref_bullets)}, max={max(pref_bullets)}")

    print("\nAverage Bullet Point Length (chars):")
    print(f"  GPT:          {sum(gpt_lengths)//len(gpt_lengths) if gpt_lengths else 0}")
    print(f"  Preference_RL: {sum(pref_lengths)//len(pref_lengths) if pref_lengths else 0}")

    print(f"\nExample Phrases Used:")
    print(f"  GPT:           {len(gpt_examples)} examples")
    print(f"  Preference_RL:  {len(pref_examples)} examples")

    # Count by label
    print("\nBy Label:")
    for label in ["AI", "Human"]:
        gpt_label = [gpt_by_id[id]['explanation'] for id in common_ids 
                     if gpt_by_id[id]['label'] == label]
        pref_label = [pref_by_id[id]['explanation'] for id in common_ids 
                      if pref_by_id[id]['label'] == label]

        print(f"\n  {label}:")
        print(f"    GPT:           {len(gpt_label)} texts, "
              f"avg {sum(count_bullet_points(e) for e in gpt_label)/len(gpt_label):.1f} bullets")
        print(f"    Preference_RL:  {len(pref_label)} texts, "
              f"avg {sum(count_bullet_points(e) for e in pref_label)/len(pref_label):.1f} bullets")

    # Sample comparisons
    print("\n" + "="*70)
    print("Sample Explanations")
    print("="*70)

    samples = list(common_ids)[:3]
    for text_id in samples:
        gpt_res = gpt_by_id[text_id]
        pref_res = pref_by_id[text_id]

        print(f"\n{'='*70}")
        print(f"Text ID: {text_id} ({gpt_res['label']})")
        print(f"{'='*70}")

        print(f"\nGPT-4o:")
        print(gpt_res['explanation'][:300])
        if len(gpt_res['explanation']) > 300:
            print("...")

        print(f"\nPreference_RL:")
        print(pref_res['explanation'][:300])
        if len(pref_res['explanation']) > 300:
            print("...")

    print("\n" + "="*70)


def main():
    print("\nLoading GPT results...")
    gpt_results = load_latest_results(GPT_RESULTS_DIR)

    print("\nLoading Preference_RL results...")
    pref_rl_results = load_latest_results(PREF_RL_RESULTS_DIR)

    if not gpt_results or not pref_rl_results:
        print("Error: Could not load results from one or both directories")
        return

    print(f"\nGPT results: {len(gpt_results)} texts")
    print(f"Preference_RL results: {len(pref_rl_results)} texts")

    compare_explanations(gpt_results, pref_rl_results)


if __name__ == "__main__":
    main()
```

## Expected Differences

### Typical GPT-4o Output
```
- Look for consistent use of complex sentence structures with multiple dependent clauses.
- Look for professional tone indicators like "regarding", "utilize", "implement".
- Look for abstract language patterns without personal anecdotes like direct experiences.
```

### Typical Preference_RL Output
```
- Look for run-on sentences joined by commas and conjunctions like "and", "but", "so".
- Look for casual conversational phrases like "honestly", "thing is", "long story short".
- Look for personal anecdotes about past behavior or experiences.
```

### Why Different?
1. **GPT**: General knowledge about writing style
2. **Preference_RL**: Trained on human-selected pairs (focused on distinguishing features)

## Cost-Benefit: Which to Use?

### Use GPT When:
- ✅ Need quick comparison with state-of-the-art
- ✅ Want to test different models (4o, 4, 3.5-turbo)
- ✅ Don't have a trained model yet
- ✅ Need online API access
- ✅ Have budget for API calls (~$1-6)

### Use Preference_RL When:
- ✅ Want free, fast inference
- ✅ Already have trained model
- ✅ Need offline inference
- ✅ Want consistent results
- ✅ Want to serve many users cheaply
